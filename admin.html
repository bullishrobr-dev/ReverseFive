Local Print Server (Recommended)

For reliable thermal printing with logo and QR code. This tiny program runs on your shop computer and sends raw printer commands directly to your BIXOLON — bypassing the Windows driver completely.

Step 1: Download (one time)

Right-click each link → Save Link As → put both files in the same folder on your shop computer:

Download printer-server.py Download start-printer.bat

Step 2: Start the server (every day)

Double-click start-printer.bat. A black window opens showing "Zero Lines Thermal Print Server".

Leave this window open while you work. It does not interfere with your POS system.

Step 3: Print

Click Print Receipt above. The receipt prints instantly — no dialog, no popups. Logo, QR code, text — everything.

Troubleshooting

  • If nothing prints, check that the black server window is still open
  • If you see "Cannot open printer", open printer-server.py in Notepad and change PRINTER_NAME to match your exact printer name from Windows Settings
  • The POS system and this server can run at the same time — they do not conflict
